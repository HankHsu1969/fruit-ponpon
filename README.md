# 水果碰碰

玩法和「西瓜遊戲 (Suika Game)」相同的網頁遊戲，有完整的碰撞與重力物理。

## 怎麼玩

- 移動滑鼠或手指選擇位置，**點一下**（觸控是**放開**）就放下水果。
- 兩個**相同的水果**碰在一起，會合成下一階的水果並得分。
- 進化順序（每一階顏色都不同）：櫻桃(紅) → 藍莓(藍) → 葡萄(紫) → 橘子(橘) → 檸檬(黃) → 青蘋果(黃綠) → 水蜜桃(粉) → 椰子(奶茶棕) → 火龍果(桃紅) → 哈密瓜(薄荷綠) → **西瓜**
- 兩顆西瓜相遇會一起消失（西瓜派對！）。
- **水果雨**：時間到就直接從箱口灑下一小批小水果（櫻桃、藍莓，偶爾葡萄）。一開始每 30 秒一次，每玩 5 分鐘間隔少 5 秒（30 → 25 → 20 → 15 → 10），到 10 秒後不再減少。每次升階，背景音樂也會加快、升調並加入更多樂器，每陣水果雨也會多一顆（4 → 6 顆）。
- 水果超過箱口的紅線約 2.4 秒就結束遊戲。
- 得分：合成出第 n 階水果得 n(n+1)/2 分（櫻桃合成藍莓得 1 分 … 合成西瓜得 55 分，兩顆西瓜消失得 66 分）。

鍵盤：`← →` / `A D` 移動、`空白鍵` / `↓` 放下、`P` / `Esc` 暫停、`M` 音樂、`N` 音效、`T` 切換白天/夜晚主題。

## 執行

直接用瀏覽器打開 `index.html` 就能玩。也可以開本機伺服器：

```bash
python -m http.server 8791
```

然後開啟 http://localhost:8791。字型（Huninn、Baloo 2）會從 Google Fonts 載入，沒有網路時會改用系統字型。

## 專案結構

| 路徑 | 說明 |
|---|---|
| `index.html` | 版面、封面、玩法說明 / 暫停 / 結束畫面 |
| `css/style.css` | 粉嫩糖果風樣式（白天 / 夜晚主題、手機直式版面、用字型繪製的標題） |
| `js/physics.js` | 自製圓形剛體物理引擎（XPBD 子步驟）：重力、碰撞、靜/動摩擦、滾動、反彈 |
| `js/audio.js` | Web Audio 即時合成的背景音樂（白天馬林巴 / 夜晚 Lo-fi，依難度階段加速升調）與所有音效，不需要音檔 |
| `js/game.js` | 遊戲邏輯：投放、合成、計分、危險判定、特效、輸入、存檔 |
| `js/assets.js` | 自動產生的素材尺寸資料（水果本體圓心與半徑） |
| `assets/` | 用 Higgsfield（GPT Image 2）產生的水果、吉祥物小雞、桌機 / 手機版背景與封面、蝴蝶結 |
| `tools/` | 素材去背裁切腳本、物理壓力測試 |

## 調整難度

在 `js/game.js` 開頭：

- `FRUITS[].r`：各水果半徑。小水果越大，箱子越快滿。
- `OVER_LIMIT`：超過紅線幾秒會結束。
- `SPAWN_WEIGHTS`：前五種水果出現的機率。
- `WAVE_INTERVALS` / `STAGE_SECONDS` / `WAVE_LEVELS`：各階段的水果雨間隔、每幾秒升一階、各種小水果的機率；顆數在 `planWave()` 裡。
- 音樂各階段的速度倍率與移調：`js/audio.js` 的 `STAGE_TEMPO` / `STAGE_KEY`。
- `BOX_W` / `BOX_H`：箱子大小。

修改物理後可以跑壓力測試，檢查穿透、爆衝和效能：

```bash
node tools/physics_stress_test.js "" 1 12 wave
```

## 重新產生素材

1. 用 H站（Higgsfield）產生白底的水果圖 `0.png`～`10.png`、`mascot.png`、`bg_day.png`、`bg_night.png`，放在同一個資料夾（例如 `raw/`）。
2. `python tools/cutout.py raw out`：白底去背，並找出水果本體的圓。
3. `python tools/mascot_crop.py out 885`：裁掉吉祥物下方的籃子（數字是裁切高度）。
4. `python tools/finalize.py <放 raw/ 和 out/ 的資料夾> .`：輸出到 `assets/` 並重新產生 `js/assets.js`。
